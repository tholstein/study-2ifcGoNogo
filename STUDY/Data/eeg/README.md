# 📁 Data Available on OSF

This folder does not contain the eeg data directly, as they are either too large and better hosted externally.

**The full dataset is available for download on the Open Science Framework (OSF):**

🔗 [Access the data on OSF](https://osf.io/d4gkb/)

---
## Dataset Contents
The dataset hosted on OSF includes:

- EEG raw data in BIDS format
- Epoch data in the derivatives folder
---

## How to Download
1. Open the OSF link above
2. Go to the **"Files"** tab
3. Download the full dataset or select individual files

---

📌 **Note:** If you use these data in your work, please cite the corresponding OSF project and consult the **"Citations"** section on the OSF page.
